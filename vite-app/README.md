# АТУ · Веб-кабинет (Stage W1–W4)

```powershell
cd vite-app
npm ci
npm run dev
```

Откройте адрес из вывода Vite. Кнопка «Открыть деморежим» доступна при локальном запуске без базы. Чтобы пройти демонстрационный сценарий, верните отчёт с комментарием, нажмите «Имитировать отправку с телефона» и примите повторно поступивший отчёт. Решения видны в истории до перезагрузки страницы.

В «Контроле сдачи» можно посмотреть статусы за выбранный месяц. Кнопка напоминания открывает черновик письма ответственному в почтовом приложении. В «Едином реестре» доступны принятые взвешивания за месяц, квартал или диапазон дат. Итоги массы и CO₂-экв. учитывают все записи под выбранными фильтрами, включая другие страницы таблицы.

В «Аналитике» выберите месяц или квартал для просмотра массы отходов, переработки и CO₂-экв. Графики и рекомендации используют только принятые записи. Для отклонений сравниваются до трёх предыдущих месяцев, а в расчёт попадают серии с данными хотя бы за два. Источники и допущения для ЦУР 12.3 и ESG приведены под графиками. У аккаунта `rectorate@atu.edu.kz` доступны аналитика и единый реестр в режиме чтения.

Для сквозной проверки с мобильным приложением:

1. Используйте один проект Supabase для web и mobile. На **пустую демобазу** примените общий `supabase_schema_and_seed.sql` из ТЗ: он пересоздаёт таблицы и демоданные.
2. После общей схемы примените [`w1_approved_lock.sql`](supabase/w1_approved_lock.sql) из папки `vite-app/supabase`. Он блокирует правки и удаление принятых отчётов и их взвешиваний.
3. Скопируйте `.env.example` в `.env.local`, заполните URL и публичный ключ проекта (`VITE_SUPABASE_PUBLISHABLE_KEY` или `VITE_SUPABASE_ANON_KEY`), перезапустите Vite. Серверный ключ в браузере не используется.
4. Войдите как `inspector@atu.edu.kz` с демопаролем из ТЗ. Вход использует `authenticate_user` из общей схемы, поэтому отдельно создавать пользователя в Supabase Auth для этого демо не нужно.
5. Отправьте отчёт в mobile. В web новый отчёт появится вверху очереди, а после возврата и повторной отправки его можно принять. В `status_history` будут записаны переходы, а взвешивания принятого отчёта появятся в `v_approved_registry`.

Очередь подписывается на [Supabase Realtime](https://supabase.com/docs/guides/realtime/postgres-changes) для `public.reports`. Если автообновление недоступно, проверьте, что `reports` входит в публикацию `supabase_realtime`; кнопку обновления можно использовать и без подписки.

Общая схема предназначена для демо: её RLS разрешает прямые операции с данными, а `authenticate_user` проверяет пароль без выдачи токена Supabase Auth. Перед размещением с реальными данными нужны согласованные между mobile и web аутентификация и серверные политики доступа.

В «Сводных отчётах» выберите месяц, квартал или год. «Скачать Excel» выгружает сводку, детальный реестр и экологический расчёт. В печатном окне «Печать / PDF» выберите «Сохранить как PDF». Для старых таблиц скачайте шаблон из блока импорта. После проверки записи сохраняются в черновики или возвращённые отчёты. Совпадающие строки пропускаются, а при ошибке пакет не сохраняется.

Для создания организаций и ответственных, импорта и отправки из QR-формы примените в Supabase SQL Editor [миграцию W4](supabase/w4_operations.sql) после общей схемы и W1. Для существующей базы запускайте только нужную миграцию. Войдите как `admin@atu.edu.kz` с демопаролем из ТЗ и откройте «Администрирование». При создании точки выберите организацию, с которой скопировать список отходов. Учётная запись руководства может выгружать сводные отчёты.

QR открывает мобильную веб-форму этой точки. Ответственный входит со своей рабочей почтой и паролем, добавляет взвешивания и отправляет месячный отчёт. Для телефона используйте адрес кабинета, доступный в его сети. При локальном запуске можно запустить `npm run dev -- --host 0.0.0.0` и открыть сетевой адрес Vite. Параметр `VITE_PUBLIC_WEB_URL` задаёт адрес этого приложения в QR.

«Открыть демо-админку» работает без миграции. Демо-точки, сотрудники и записи W4 хранятся в текущем браузере. В демо-форму входят с почтой ответственного и паролем `atu2026`.

Проверки проекта: `npm run lint` и `npm run build`.
