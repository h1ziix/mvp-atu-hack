# ♻️ ATU EcoVision

Платформа учёта, аналитики и отчётности по производственным отходам с AI-ассистентом (голос, фото, текст), разработанная в рамках хакатона **ATU**.

---

## 📂 Структура репозитория (Ветки)

Проект разделён на две основные ветки:

| Ветка | Описание | Ссылка |
| :--- | :--- | :--- |
| 🌐 **`web`** | **Веб-приложение** — панель администратора и аналитики, управление справочниками, филиалами, нормами, отчётами и генерация QR-паспортов площадок | [Перейти в ветку `web` →](https://github.com/h1ziix/mvp-atu-hack/tree/web) |
| 📱 **`mobile`** | **Мобильное приложение (Expo / React Native)** — полевой терминал оператора, AI Smart Input (голос / фото-сканер / текст), офлайн-очередь, QR-сканер и быстрый ввод партий отходов | [Перейти в ветку `mobile` →](https://github.com/h1ziix/mvp-atu-hack/tree/mobile) |

---

## 🚀 Быстрый переход по командам Git

**Веб-приложение (`web`):**
```bash
git checkout web
```

**Мобильное приложение (`mobile`):**
```bash
git checkout mobile
```

---

## 🛠 Единый бэкенд
Оба приложения работают с единой базой данных **Supabase** (PostgreSQL + RLS + Storage) и общими **Supabase Edge Functions** (`atu-ai` / `smart-input`). Подробные инструкции по запуску находятся внутри `README.md` соответствующей ветки.
